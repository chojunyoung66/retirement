# retirement-frontend

## 프로젝트 요약
이 프로젝트는 사용자가 은퇴 후 자금 흐름을 시뮬레이션하고 계획을 수립할 수 있도록 돕는 React 기반 프론트엔드 애플리케이션입니다.

사용자는 진단 유형 선택, 프로필 입력, 현금 흐름 입력, 시나리오 설정, 의료비 입력을 거쳐 예상 자산/지출 결과와 요약 화면을 확인할 수 있습니다. 로그인 후 접근 가능한 결과 화면과 현금 흐름 계획 화면도 제공하여, 은퇴 설계 과정을 단계별로 안내합니다.

## 주요 기능
- 은퇴 진단 및 사용자 프로필 입력
- 현금 흐름, 시나리오, 의료비 데이터 입력
- 예상 결과 및 요약 화면 제공
- 로그인 기반 보호 라우팅
- 토스트 메시지와 상태 관리 기반 UX

## 기술 스택
- React 19
- TypeScript
- Vite
- React Router
- Redux Toolkit
- Zod

## 실행 방법
```bash
npm install
npm run dev
```

개발 서버가 실행되면 브라우저에서 로컬 주소로 접속하면 됩니다.
